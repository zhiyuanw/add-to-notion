## Codebase Patterns
- Release checklist coverage is centralized in `src/tests/releaseChecklist.test.ts` and can import `public/manifest.json` directly.
- Build-time extension config can live in a small source module with an empty default and be injected into `dist` by `scripts/build-extension.mjs`.
- Popup-to-background save messages are the handoff point for tab-local content-script data; inject content helpers only after checking the configured base URL.
- Asset-producing conversion should emit `asset_placeholder` blocks and let the save pipeline replace them after upload, preserving document order.
- Notion file upload expiry validation belongs in asset processing and should compare `expiresAt` to attach-time `now`, not a one-hour lookahead window.
- Partial Notion writes should be represented on `ClipTaskResult.partial` and propagated into terminal summaries for Popup rendering.
