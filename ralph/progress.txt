## Codebase Patterns

- Use npm scripts as the project quality gate: `npm run build`, `npm run typecheck`, and `npm test`.
- MV3 static assets live in `public/`; extension entrypoints live in `src/background`, `src/popup`, and `src/options`.
- Shared domain contracts live in `src/shared/domain`; storage key contracts live in `src/shared/storage`.
- Route all typed `chrome.storage.local` access through `src/shared/storage/local.ts`; logout cleanup preserves Confluence base URL.
- Normalize and validate Confluence base URLs through `src/confluence/baseUrl.ts`; store them via `saveConfluenceBaseUrl`.
- Request and check Confluence host permissions through `src/confluence/permissions.ts`; permissions are origin-scoped, not context-path-scoped.
- Options UI logic can be tested with `happy-dom` and exported mount/render helpers from `src/options/index.ts`.
- Mount the full Options page through `mountOptionsPage`; keep section-specific helpers testable with injected dependencies.
- Notion OAuth helpers live in `src/notion/oauth.ts`; inject `fetcher`, `now`, and `createState` in tests instead of relying on real network or time.
- Notion auth/session helpers live in `src/notion/auth.ts`; use `notionApiFetch` before Notion API calls so expired tokens refresh and failed refresh clears session state.
- Notion target discovery helpers live in `src/notion/targets.ts`; target selection persists through `storageKeys.notionDefaultTarget`.
- Confluence page detection lives in `src/confluence/detector.ts`; it must check host permission and enforce the normalized base URL context path before matching page URL forms.
- Confluence storage fetching lives in `src/confluence/fetcher.ts`; it uses `credentials: 'include'`, enforces the base URL path, and maps recoverable HTTP failures to typed reasons.
- Route external HTTP calls through `src/shared/request.ts` to apply 30s timeout, retry policy, 429 retry hints, and caller-provided deadlines.
- Parse Confluence storage XML through `src/confluence/storageParser.ts`; it preserves namespace-qualified nodes, blocks external entities, degrades unsafe raw HTML, and returns typed parse failures.
- Convert supported Confluence storage AST content through `src/converter/index.ts`; it emits Notion block objects directly instead of using Markdown.
- Macro conversion belongs in `src/converter/index.ts` by detecting `ac:structured-macro`; macro-heavy fixtures should cover supported and unknown macros.
- Asset discovery lives in `src/assets/index.ts`; it consumes parsed storage AST plus `ConfluencePageData.attachments` and classifies same-origin assets independently from context-path guards.
- Asset processing lives in `src/assets/index.ts`; use `processConfluenceAssets` with injected fetch/upload hooks in tests and keep source-link degradations as warnings.
- Asset rendering also lives in `src/assets/index.ts`; use `renderProcessedAssetsToNotionBlocks` to turn processed assets into Notion file/image blocks or link fallbacks without per-image callouts.
